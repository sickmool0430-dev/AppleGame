# 자바 사과 게임

자바 기본 문법과 Swing을 사용하는 학습용 게임입니다. 클래스는 역할에 따라 분리하고, 모드 차이는 조건문으로 처리합니다.

## 실행

JDK 8 이상을 설치한 뒤 `run.bat`을 실행합니다. IDE에서는 이 폴더를 작업 폴더로 지정하고 `Main.java`를 실행합니다.

```powershell
New-Item -ItemType Directory -Force out | Out-Null
javac -encoding UTF-8 -d out Main.java GameApp.java HomePanel.java AppleGame.java AppleBoard.java BoardPanel.java EndPanel.java GameStyle.java RoundButton.java GameRecords.java
java -cp out Main
```

이미지 두 개는 실행에 필요하므로 `run.bat`과 같은 폴더에 둡니다.

- `image-Photoroom (40).png`: 일반 사과
- `image-Photoroom (41).png`: 배드 애플 사과

`records.txt`는 완료 기록과 히든 모드 해금 자격을 보관합니다. `out`은 다시 생성할 수 있는 컴파일 결과 폴더입니다.

## 게임 규칙

일반 모드는 1~9, 배드 애플은 -3~-1, 1~9, 11~13 중에서 숫자를 무작위로 배치합니다. 마우스로 드래그한 사각형 안의 숫자 합이 10이면 그 안의 사과를 제거합니다. 배드 애플에서는 `13 + (-3)`도 지울 수 있습니다. 이미 지운 칸은 0으로 계산합니다.

| 항목 | 일반 모드 | 배드 애플 모드 |
| --- | --- | --- |
| 사과 수 | 10 × 10 | 15 × 15 |
| 제한 시간 | 60초 | 120초 |
| 점수 | 누적 제거 개수 | 누적 제거 개수 ÷ 2를 반올림 |
| 화면 | 분홍색 테마, 40번 이미지 | 어두운 테마, 41번 이미지 |

배드 애플 점수는 누적 개수로 계산합니다. 3개를 제거하면 2점, 3개를 더 제거해 총 6개가 되면 3점입니다.

진행 중 상단의 `홈`을 누르면 타이머가 멈추고 현재 모드의 홈으로 바로 이동합니다. 중간에 나간 판은 순위에 기록하지 않습니다. 시간이 끝나거나 제거할 조합이 없으면 종료 화면이 나타납니다. `다시하기`는 새 게임을 시작합니다. 창 크기를 바꿔도 게임판과 사과의 비율을 유지합니다.

## 일시정지

게임 상단의 `일시정지` 버튼을 누르면 타이머와 드래그 입력을 멈추고, 중앙에 `계속하기`와 `홈` 버튼을 표시합니다. 일반 모드와 배드 애플 모두 같은 방식입니다.

- `계속하기`: 같은 판, 점수, 남은 시간으로 재개
- `홈`: 진행 중인 판을 끝내고 홈으로 이동, 완료 기록에는 미포함
- 일시정지할 때 진행 중이던 드래그는 취소, 재개 후 새로 선택
- 종료된 게임에서는 일시정지 불가, 새 게임에서는 정지 상태 초기화

구현은 `AppleGame`의 `boolean paused`로 상태를 구분합니다. `togglePause()`에서 값을 바꾸고 `timer.stop()` 또는 `timer.start()`를 호출합니다. 타이머와 마우스 이벤트는 `paused`가 참이면 처리하지 않습니다. 기존 `EndPanel`을 재사용하므로 별도의 일시정지 화면 클래스를 만들지 않습니다.

## 히든 모드와 기록

일반 게임 한 판에서 50점 이상을 달성한 뒤, 홈의 큰 사과 이미지를 왼쪽 마우스로 44번 누르면 배드 애플 홈으로 이동합니다. 배드 애플 홈 사과를 7번 누르면 일반 홈으로 돌아옵니다. 자격을 얻기 전의 클릭과 투명한 여백 클릭은 세지 않습니다. 게임 시작, 홈 이동, 모드 전환 시 클릭 횟수는 초기화됩니다.

홈 사과를 누르면 90%로 작아졌다가 약 0.08초 동안 원래 크기로 돌아옵니다. `appleScale`을 0.90으로 바꾸고 타이머에서 0.02씩 더하는 방식입니다. 클릭 영역은 원래 크기를 유지합니다.

홈 상단 왼쪽은 해당 모드의 전체 완료 기록을 높은 점수순으로 표시하고, 오른쪽은 평균을 소수점 한 자리로 표시합니다. 일반 기록과 배드 애플 기록은 분리됩니다.

어느 홈에서든 `기록 초기화 → 지우기`를 선택하면 해당 모드의 기록이 비워지고 배드 애플이 다시 잠깁니다. 일반 홈에서 새로 시작해 한 판에서 50점 이상을 얻은 뒤 사과를 44번 누르면 다시 입장할 수 있습니다. `취소`를 누르면 기존 기록과 자격이 유지됩니다.

시간 종료 또는 제거 가능한 조합이 없어 종료된 판만 한 번 기록합니다. 일시정지, 진행 중 다시 시작, 홈 이동, 창 닫기는 완료 기록에 포함하지 않습니다. 50점 달성 자격은 달성 즉시 저장합니다.

`records.txt`는 프로그램 작업 폴더에 저장됩니다. `run.bat`으로 실행하면 이 프로젝트 폴더입니다. 저장 실패 시 홈 기록 창 아래에 안내를 표시합니다. 앱을 다시 실행하면 일반 홈에서 시작하며, 기록과 해금 자격은 유지됩니다.

## 파일별 역할

| 클래스 | 역할 |
| --- | --- |
| Main | 프로그램 실행과 창 생성 |
| GameApp | 홈·게임 전환, 모드와 사과 클릭 횟수 관리 |
| HomePanel | 홈 화면, 순위·평균, 사과 클릭 효과 |
| AppleGame | 마우스 입력, 시간, 일시정지, 종료 처리 |
| AppleBoard | 숫자 배열, 합 계산, 삭제, 점수 계산 |
| BoardPanel | 크기에 맞춰 게임판과 선택 영역 그리기 |
| EndPanel | 종료·일시정지 안내와 버튼 표시 |
| GameRecords | 모드별 기록 저장, 순위와 평균 계산 |
| GameStyle | 공통 색, 글꼴, 이미지 읽기와 그리기 |
| RoundButton | 둥근 버튼 그리기 |

## 코드 설명

`AppleBoard`의 `numbers[행][열]`에 사과 숫자를 저장합니다. 0은 빈칸입니다. `getSum()`은 선택 영역을 이중 반복문으로 돌며 합을 구하고, `remove()`는 합이 10일 때만 사과를 0으로 바꾸고 제거 개수를 더합니다.

`hasAvailableMove()`는 사각형의 위·왼쪽·아래·오른쪽 경계를 정하는 네 개의 반복문으로 가능한 사각형을 모두 검사합니다. 합이 10인 곳을 찾으면 true, 끝까지 없으면 false를 반환합니다.

`BoardPanel.cellSize()`는 가로와 세로에 들어갈 칸 크기 중 작은 값을 사용합니다. 그리기와 클릭 좌표 계산에 같은 크기와 시작 위치를 사용하므로 창을 늘려도 선택 위치가 어긋나지 않습니다.

`GameStyle`은 PNG 두 개를 한 번만 읽어 재사용합니다. 이미지 비율과 투명 배경을 유지하고, 게임판에서는 숫자를 덧그립니다.

화면 클래스는 `JPanel`, 둥근 버튼은 `JButton`을 상속합니다. `paintComponent()`를 재정의해 화면을 그리고, 숫자 배열과 점수는 private으로 두고 메서드로 접근합니다. `GameApp`의 `CardLayout`은 홈과 게임을 전환하며, `AppleGame`의 `OverlayLayout`은 안내 화면을 게임 위에 겹칩니다.
